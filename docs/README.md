# Tactile Room: project records

This folder keeps the record of how Tactile Room is made: decisions, reasons, tests and feedback.
It lives next to the code so every change and its reason stay together in the Git history.

- `project-report.md`: the project report (copy it here from the Claude Project
  "MY LONG-TERM CAREER, EDUCATION & CREATIVE STRATEGY AI", file `projects/tactile-room-project-report.md`).
- `../CHANGELOG.md`: what changed in each version, with the date and reason.
- `../versions/`: each earlier version kept exactly as it was.

Published at https://tactileroom.chicomorais.com (GitHub Pages, branch `main`, folder `/`).
